# Huisartsenpraktijk Smits & Canoy — website

Statische website (Jekyll, GitHub Pages) voor Huisartsenpraktijk Smits & Canoy in Hardinxveld-Giessendam.

Zie **[HANDLEIDING.md](HANDLEIDING.md)** voor publiceren en onderhoud.

## Structuur

```
_config.yml         instellingen (o.a. baseurl)
_data/              praktijkgegevens, menu, medewerkers, veelgestelde vragen
_includes/          header, footer, praktijkinfo, nieuwslijst, faq, ...
_layouts/           default (basis), page (tekstpagina), post (nieuwsbericht)
_posts/             nieuwsberichten
assets/             css, js, lettertypen, afbeeldingen, documenten
ons-team/ formulieren/ handige-info/   pagina's per menu-onderdeel
```
